# Property-Sales

## Steps to Run and Contribute

1. Clone the repository.
2. Install project dependencies:

   ```bash
   npm install
   ```
3. Switch to the developer branch:

   ```bash
   git checkout developer
   ```
4. Create your feature branch from the developer branch:

   ```bash
   git checkout -b <your-feature-branch>
   ```
5. Implement your feature and commit your changes.
6. Push your feature branch:

   ```bash
   git push origin <your-feature-branch>
   ```
7. Raise a Pull Request (PR):

   * From: `<your-feature-branch>`
   * To: `developer`
8. Once the PR is reviewed and approved:

   * The `developer` branch will be merged into the `main` branch.
